# X & Reddit 社区热议 · 写稿规范

你要把 `x_report.py --mode fetch` 输出的素材写成一份中文播报，存到 `logs/report_draft.txt`，
再由 `x_report.py --mode send` 推送飞书并同步归档至 Notion。

## 这份播报在 09:00 四合一流水线里的位置

每日 09:00 串行顺序：`1. AI 产业日报 → 2. X & Reddit 社区热议（本篇）→ 3. AI Builder 日报 → 4. GitHub & HN`。

用户每天看本篇的目的只有一个：知道 **X 与 Reddit 上 AI 圈真正在吵什么、一线开发者真机实测翻车在哪**，并能**一键跳到关键原帖现场**。
- **X 主体（1–4 条）**：深度聚焦过去 48 小时讨论中心度最高、存在真正正反交锋或第三方实测打脸的焦点争论；果断砍掉只有 1 次顺带提及的边角料、招聘/活动宣发与客套吹水。
- **🔧 工程快讯（可选，0–2 条）**：针对 AINews 中高含金量的硬核硬件/内核/系统实测（如 SemiAnalysis 算力 TCO 拆解、DeepSeek 底层内核更新、API 协议载荷暴降等），若明显不属于“多方吵架”且大概率不在第 3 棒自建 X List 关注名单中，可在此用 1–2 句精炼兜底，消除 X 与 Builder 之间的盲区；没有值得兜底的硬核工程料时整块省略。
- **🗣️ Reddit 实测与吐槽（1–2 条，置于 `📎 主流媒体同期在报` 之前）**：专挑 **X 主体未展开（或带出截然不同的一线真机实测/量化翻车/工具踩坑视角）** 的高活跃度议题（来自 `r/LocalLLaMA`、`r/OpenAI`、`r/ClaudeAI`、`r/GeminiAI` 等 12 个核心 AI subreddit）。无独立增量或无 Reddit 素材时整块省略，绝不硬凑。

## 前序去重规则（承接第 1 棒《AI 产业日报》）

对照 `last_context.txt` 顶部的 `TODAY_LEDGER`：
1. 若某事件已在当早《AI 产业日报》播过客观事实，且 X / Reddit 上只是单向转发官宣、无实质技术分歧 → **直接跳过**。
2. 若该事件在社区引发了激烈交锋、量化打假或第三方实测质疑 → **直接切入正反方观点与实测数据**，绝不重复复述《AI 产业日报》已交代的新闻背景。

## 硬性要求

1. **精选关键行内链（告别“蓝字轰炸”）+ 文末单条主原帖：**
   - **X 板块行内链接**：每条 X 话题正文中**精选 2–4 个最关键的链接**（核心爆料方、最尖锐反驳方、或关键实测/开源仓库），挂 `<a href="URL">`；其余次要陪跑人物或机构直接写纯文本（如 `@handle` 或机构名），保持阅读流清爽，让读者一眼看清真正值得点的现场！
   - **X 板块文末主原帖**：每条 X 话题末尾只选 **1 条代表性最高（互动量最高或被引用最多）的 `x.com/<user>/status/<id>` 原帖直链**贴在 `原帖：` 行。`send` 模式会强校验，全篇无 X 原帖直链直接拒发。
   - **Reddit 板块原帖直链**：标题格式 `<b>[r/{Subreddit}] {话题标题}</b>`，末尾 `原帖：` 行贴 `https://www.reddit.com/r/.../comments/...` 直链，并如实标注 `（AINews 活跃度 {N}）`（素材未标时省略括号）。
2. **所有链接必须真实来自素材**（`原帖排行`、`Twitter Recap 正文`、`Reddit 原帖排行` 或 `Reddit Recap 正文`），绝对禁止编造或拼接 URL / status id。
3. **热度口径严格诚实（优先用 AINews 真实互动量）：**
   - 若 `原帖排行` 中标出了 `[互动 26.3k · 提及 2 次]`，文末优先写真实互动量：`原帖：<a href="...">@{handle}</a>（AINews 标注互动 26.3k）`；
   - 若未标出互动量，则如实写：`原帖：<a href="...">@{handle}</a>（当天复盘被引用 {N} 次）`，切勿把被引用次数写成点赞数。
   - Reddit 板块照实写 `AINews 活跃度 N`，不写成点赞数或评论数。
4. **保留正反分歧 & 标清未证实传闻**：AINews 的 recap 包含 `Supportive / Neutral / Critical` 及 `speculative / unsubstantiated` 提示；每条争议话题尽量呈现“支持/爆料方怎么说、质疑/打假方怎么反驳”；**未经证实的传闻不得与主流媒体实锤事件混写成同一事实**，必须显式注明“尚未证实”。
5. **只用 `<b>` 和 `<a href>` 两种标签**，严禁 Markdown `**`、`###` 或其他 HTML 标签。

## 输出结构

各区块、段落与链接行之间空一行隔开：

```
<b>🔥 X & Reddit 社区热议 · {日期}</b>

{一句话概括过去 48 小时 X 与 Reddit 上最核心的争论与实测主线}

<b>1. {X 话题标题，≤24 字}</b>

{2–4 句：发生了什么、关键实测数据或核心指控，精选关键争议方随文挂链}

{分歧：谁支持、谁反驳/质疑，各一两句，给出具体依据与数据}

原帖：<a href="{x.com 直链}">@{handle}</a>（AINews 标注互动 {26.3k} 或 当天复盘被引用 {N} 次）

<b>2. …</b>

<b>🔧 工程快讯</b>

- <a href="{x.com 或技术外链}"><b>{硬核系统/硬件/开源实测标题}</b></a>：{1–2 句核心量化数字与工程机制。无合适条目时整块省略}

<b>🗣️ Reddit 实测与吐槽</b>

<b>[r/{Subreddit}] {Reddit 增量话题标题}</b>

{2–4 句：原帖核心发布/实测数据 + 评论区最尖锐的质疑、翻车反馈或工程共识}

原帖：<a href="{reddit.com 直链}">r/{Subreddit} 原帖</a>（AINews 活跃度 {N}）

<b>📎 主流媒体同期在报</b>

{Techmeme 里与上面话题对得上的 2–3 条，一行一条，带链接。对不上就整块省略}

<b>素材</b>：AINews {期次日期}（<a href="{issue url}">原文</a>）· X Twitter Recap + Reddit Recap
```

- X 话题 **1–4 条**，`🔧 工程快讯` **0–2 条**（无则略），`🗣️ Reddit 实测与吐槽` **1–2 条**（无独立增量则略），宁少勿滥；篇幅目标 1200–2400 字。

## 语气红线

写给已经很懂 AI 的人看。不科普基础概念、不堆感叹号、严禁 AI 腔旁白（禁止「值得注意的是」「原因并不复杂」「这标志着」「给出了一个反直觉的判断」「深度」「赋能」「颠覆」「重磅」）；把判断直接归给具体发帖人、评测方或评论者，用事实和数字说话。

## 素材标记

| 标记 | 含义 |
|---|---|
| `=== FETCH_OK ===` | 取材成功，往下读 |
| `=== NO_TOPICS ===` | 窗口内无未播新刊，**今天不写稿**，直接汇报跳过 |
| `=== SKIP_ALREADY_RAN ===` | 今天已播过，停手 |
| `=== SKIP_PROXY ===` | 代理不可用，停手并提醒用户 |
| `=== SOURCE_ALERT ===` | 某 provider 连续零产，**在稿尾用一行提示用户排查** |
| `（已播过，勿作为新料）` | 此前已播过的原帖，可作背景提及但不要当新料 |
